# دليل بناء وتنصيب MfgSystem — الإصدار 1.50.74

## المكونات الحالية

| الملف | الوظيفة |
|---|---|
| `1-بناء_الحزمة.bat` | استعادة الحزم، الاختبارات، والنشر إلى Windows x64 |
| `2-تنصيب.bat` | تنصيب الحزمة الجاهزة وإنشاء الاختصارات |
| `فحص_المتطلبات.bat` | فحص النظام والقرص والذاكرة قبل التنصيب |
| `إلغاء_التنصيب.bat` | إزالة البرنامج مع إبقاء البيانات حتى التأكيد |

## البناء من المصدر

يتطلب Windows و.NET 8 SDK. من جذر المشروع شغّل:

```bat
Installer\1-بناء_الحزمة.bat
```

يتحقق السكربت من SDK، ينفذ `dotnet restore` و`dotnet test`، ثم ينشر:

```text
MfgSystem_Publish\MfgSystem.exe
```

ويولد `VERSION.txt` و`SHA256.txt` وحزمة `MfgSystem_FULL.zip`.

## التنصيب على جهاز Windows

1. انسخ مجلد `MfgSystem_Publish` أو استخرج `MfgSystem_FULL.zip`.
2. شغّل `2-تنصيب.bat`.
3. يتحقق السكربت من سلامة `MfgSystem.exe`، ثم ينسخ البرنامج وينشئ اختصار سطح المكتب وقائمة Start.
4. يمكن تشغيل `فحص_المتطلبات.bat` قبل التنصيب عند الحاجة.

## البيانات والاتصال

يستخدم البرنامج مجلد البيانات الخاص به تحت `%LocalAppData%\MfgSystem`.
يتم اكتشاف اتصال SQL Server أو استخدام الوضع المحلي وفق إعدادات النظام الحالية.
لا يغير هذا المثبت قاعدة البيانات أو إعدادات الاتصال.

## الإزالة

شغّل `إلغاء_التنصيب.bat` من مجلد البرنامج. يحتفظ السكربت بالبيانات افتراضياً ولا يحذفها إلا بعد تأكيد صريح.

> لا تُنشأ حزم نشر أو تحديثات قديمة من هذا المجلد. ملف الحل الرسمي للمشروع هو `DateERP.sln` في جذر المستودع.
