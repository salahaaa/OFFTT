الإصدار 1.50.72

تثبيت MfgSystem بنقرة واحدة

حزمة مستقلة تبدأ بقاعدة SQLite محلية جديدة عند أول تشغيل، ولا تستخدم قواعد أو مجلدات DateERP السابقة.

التثبيت الأول

  1. نزّل ZIP الفرع الحالي واستخرجه إلى مجلد جديد، مثل D:\MfgSystem_1.50.72. لا تستخرج فوق مجلد نسخة قديمة.
  2. من جذر المجلد، شغّل INSTALL-AND-RUN.bat كمسؤول ووافق على UAC.
  3. يتحقق المثبّت من .NET 8 SDK، ويثبته إذا لزم، ثم يستعيد حزم NuGet وينشر نسخة Windows x64 داخل Application_1.50.72.
  4. ينشئ اختصار سطح المكتب ويشغّل MfgSystem.exe.

إذا كان الجهاز بلا إنترنت، نزّل من جهاز آخر مثبت .NET 8 SDK الرسمي x64 وانسخه بجانب المثبّت باسم dotnet-sdk-8-win-x64.exe. استعادة حزم NuGet ما زالت تتطلب الإنترنت أو مخزناً محلياً مكتملاً.

قاعدة البيانات والفصل عن النسخ السابقة

  • إن لم يوجد إعداد MfgSystem على ملف المستخدم، ينشئ أول تشغيل ملف %LocalAppData%\MfgSystem\mfgsystem_local.db ووضعاً محلياً تلقائياً.
  • بيانات الدخول الأولية: admin / Admin@123، ويجب تغيير كلمة المرور عند الدخول الأول.
  • الإعدادات والسجلات والثيمات والمسودات تحت هوية MfgSystem. شاشة النسخ الاحتياطي تدعم SQL Server فقط ولا تنفذ نسخ SQLite المحلية.
  • المثبّت لا يستورد إعدادات DateERP ولا يحذف أو يستبدل قواعد أو ملفات قديمة. وإذا سبق استخدام MfgSystem نفسه، تُحفظ بياناته كما هي.

التشغيل اليومي

انقر اختصار MfgSystem 1.50.72، أو شغّل Installer\RUN-SYSTEM.bat من جذر المصدر.

اتصال SQL Server اختياري

المثبت لا يثبت SQL Server أو SSMS. يمكن إعداد خادم مستقل لاحقاً باسم قاعدة MfgSystemDB عبر شاشة الاتصال والملفات الاختيارية داخل Installer\server. لا تستخدم قاعدة DateFactory الخاصة بالإصدارات القديمة، ولا تشغّل نصوص SQL قبل مراجعتها.

حدود التحقق

لم تُختبر ملفات BAT أو CMD/PowerShell ولم يُنفّذ بناء .NET أو تشغيل WPF على Windows في بيئة إعداد هذه الحزمة. اختبرها على Windows نظيف قبل اعتمادها للإنتاج.
