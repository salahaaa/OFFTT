2) متطلبات الجهاز

  • ويندوز 10 أو 11 — 64 بت.
  • 25 جيجابايت فارغة على القرص C (يفضل أكثر).
  • إنترنت مستقر + صلاحية مسؤول (نافذة UAC ← اضغط Yes).

3) خطوات التنفيذ — نقرة واحدة

1. حمّل MfgSystem_1.50.50_FULL.zip من رابط التسليم.
2. استخرجه كاملاً إلى مجلد جديد مثل D:\MfgSystem — استخرجه إلى مجلد جديد تماماً مثل D:\MfgSystem — لا فوق أي نسخة قديمة.
3. انقر مرتين على تنصيب_نظام_التصنيع.bat ← وافق على UAC بـ Yes.
4. راقب نقاط التفتيش: STEP 0 صلاحية ← STEP 1 إنترنت ← STEP 3 ‏.NET ← STEP 4 ‏SQL Server ← STEP 5 ‏SSMS (اختياري) ← STEP 6 ‏Visual Studio (الأطول — قد تختفي النافذة فترات، هذا طبيعي) ← STEP 7 بناء ← STEP 8 تشغيل النظام 🎉
5. النهاية السعيدة: لافتة ALL CHECKPOINTS PASSED - SYSTEM READY والنظام مفتوح أمامك.
💡 فشل شيء؟ أصلح السبب المكتوب في سطر [FAILED] ثم أعد تشغيل نفس الملف — المكتمل يُكتشف ويُتخطى تلقائياً ولا يُعاد تحميله.

4) أول تشغيل للنظام

  • أول تشغيل ينشئ قاعدة البيانات تلقائياً (جداول + بيانات أساسية + مستخدم admin) بلا أي إعداد.
  • الوضع الأول محلي (SQLite) ليعمل فوراً، وسيقترح النظام التحويل إلى SQL Express المثبَّت — اقبل.
  • تغيير الاتصال يدوياً: داخل النظام ← معلومات النظام ← تعديل الاتصال ← الخادم .\SQLEXPRESS بمصادقة Windows.
  • كلمة سر SA الاحتياطية (لـ SSMS): MfgSystem#2026Sa

5) رؤية الشاشات وتعديلها — Visual Studio 2022

  1. من Installer انقر مرتين على OPEN-VISUAL-STUDIO.bat (يفتح Visual Studio 2022 — النافذة البنفسجية الكبيرة، ليس VS Code الأزرق الصغير).
  2. انتظر دقيقة حتى يظهر Solution Explorer على اليمين.
  3. كل الشاشات في src\DatesErp.Desktop\Views\Screens\ — لكل شاشة ملفان: .xaml (التصميم — نقر مزدوج يفتح مصمماً مرئياً) و.xaml.cs (السلوك).
  4. تجربة حية: F5 تشغيل مع تصحيح، أو Ctrl+F5 تشغيل عادي.
⚠️ قواعد الأمان المتفق عليها: نسخة .bak قبل أي تعديل · تعديلات مظهر فقط · لا تغيّر أبداً أسماء x:Name أو معالجات مثل Click="Save_Click" · التشغيل من المصدر يتصل بقاعدة البيانات الحقيقية — استعرض بحذر.

6) التشغيل لاحقاً

  • RUN-SYSTEM.bat — يشغّل النظام مباشرة (ويبنيه مرة واحدة إن لزم).
  • أو OPEN-VISUAL-STUDIO.bat ثم Ctrl+F5.

8) ملاحظات أمانة

السكربتات مبنية بمواصفات صارمة (ASCII نقية، بلا تبديل ترميز، لا تلمس قاعدة البيانات أو بياناتك، نقاط تفتيش OK/FAILED، توقف عند الفشل مع السبب، آمنة الإعادة) — لكنها لم تُختبر في بيئة CMD حقيقية لأن بيئة التطوير هنا بلا ويندوز. عند أي خطأ غير متوقع أرسل نص النافذة + install_log.txt.
