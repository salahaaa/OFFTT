# Date ERP / MfgSystem

## الحالة الحالية

هذا هو **المصدر الحالي الوحيد** لنظام إدارة وتصنيع التمور، الإصدار `1.50.74`.
اسم البرنامج التنفيذي هو `MfgSystem.exe`، والمشروع مبني بتقنية WPF على `.NET 8`.

تم دمج نظام إدارة الثيم المركزي في هذه النسخة، ويشمل الألوان والخطوط والحقول والأزرار والجداول والنوافذ وأوضاع Light/Dark/Auto، مع الحفظ داخل `SystemSettings` وحماية شاشة التخصيص بصلاحية `settings/Edit`.

> هذه شجرة المصدر الحالية وليست مستودعاً لأرشيفات التحديثات السابقة. تم الاحتفاظ بملف `UPDATE_1.50.73_FULL_SOURCE_BUILDABLE.zip` وحده كمرجع ثبات إلزامي، ولا يُستخدم للتشغيل أو التطوير.

## الحل الرسمي

يُستخدم ملف الحل الوحيد التالي:

```text
DateERP.sln
```

ويضم مشاريع المصدر والاختبارات وأدوات القبول والفحص اللازمة للمشروع الحالي.

## بنية المشروع

```text
src/
  DatesErp.Core/          الكيانات والواجهات والقواعد الأساسية
  DatesErp.Application/   خدمات ومنطق الأعمال
  DatesErp.Infrastructure/ EF Core والاتصال والتدقيق
  DatesErp.Desktop/       تطبيق WPF والشاشات والثيم المركزي

tests/DatesErp.Tests/     اختبارات النظام

tools/                    أدوات القبول والفحص الحالية

audit/                    فحص قواعد الوحدات

Installer/                سكربتات البناء والتنصيب الحالية
Documentation/            أدلة التشغيل والتنصيب الحالية
```

## البناء والتشغيل

يتطلب البناء والتشغيل الفعلي Windows 10/11 مع .NET 8 SDK.

### البناء والاختبارات

```bat
dotnet restore DateERP.sln
dotnet build DateERP.sln -c Release
dotnet test tests\DatesErp.Tests\DatesErp.Tests.csproj -c Release
```

### تشغيل نسخة التطوير

```bat
dotnet run --project src\DatesErp.Desktop\DatesErp.Desktop.csproj
```

### إنشاء حزمة Windows

من Windows فقط:

```bat
Installer\1-بناء_الحزمة.bat
```

ينفذ السكربت الاستعادة والاختبارات والنشر `win-x64` المكتفي ذاتياً وينتج مجلد `MfgSystem_Publish`.
بعد نجاح البناء يمكن تشغيل `Installer\2-تنصيب.bat` من مجلد الحزمة على الجهاز الهدف.

## قاعدة البيانات والاتصال

- لم يتم تغيير قاعدة البيانات أو إعدادات الاتصال ضمن تحديث الثيم.
- لا توجد Migration مطلوبة لنظام الثيم؛ التخزين يستخدم بنية `SystemSettings` الحالية.
- لا يتم إنشاء اتصال أو سند مخزني تلقائياً من شاشة تخصيص الثيم.
