───────────────────────────────────────────────────────────────
- زر الحفظ في PlanningView يتفعل فقط عندما تكون الخطة غير معتمدة:

- وحدة الصلاحيات لشاشة التخطيط هي الكود planning، وليست العنوان العربي.
  ويظل WithSave خاضعاً لـ PermissionGate.Can("planning", "Edit").
