# 🏭 دليل التنصيب الكامل من الصفر — نظام التصنيع (MfgSystem) الإصدار 1.50.50

> **الوعد**: ملف واحد تنقره مرتين → يُنزَّل ويُثبَّت كل شيء تلقائياً → يُبنى النظام → يفتح أمامك جاهزاً
> **بقاعدة بيانات خاصة به وحده**، ومعك Visual Studio 2022 ترى فيه كل الشاشات وتعدّلها.

## 0) 🔒 الانفصال التام عن كل النسخ السابقة (أهم بند)

هذا النظام **كيان منفصل 100%** عن أي نسخة DateERP قديمة على جهازك:

| المورد | النسخ القديمة | نظام التصنيع الجديد | هل يتعارضان؟ |
|---|---|---|---|
| مجلد الإعداد والlogs والنسخ الاحتياطية | `%LocalAppData%\DateERP_15021` | `%LocalAppData%\MfgSystem` | **لا** — مجلدان مختلفان تماماً |
| قاعدة البيانات (SQL Server) | `DateFactory` / `DateFactory_15021` | **`MfgSystemDB`** — تُنشأ تلقائياً | **لا** — قاعدتان مستقلتان على نفس المحرك |
| القاعدة المحلية (وضع SQLite) | `dateerp_local.db` | `mfgsystem_local.db` | **لا** — ملفان مختلفان |
| اسم البرنامج التنفيذي | `DateERP.exe` | **`MfgSystem.exe`** | **لا** |
| مجلد التنصيب المقترح | `D:\DateERP_...` | **`D:\MfgSystem`** | **لا** |
| اختصار سطح المكتب | `DateERP.lnk` | `MfgSystem.lnk` | **لا** |

**النتيجة**: كل نسخك القديمة تبقى تعمل بشكل طبيعي تماماً كما هي — لا يقرأ النظام الجديد بياناتها،
ولا يعدّل قواعدها، ولا يلمس مجلداتها. وحتى محرك SQL Server نفسه (إن كان مثبّتاً مسبقاً) يُعاد استخدامه
كمحرك فقط — بقاعدة بيانات جديدة مستقلة اسمها `MfgSystemDB` تُنشأ من الصفر عند أول تشغيل.

## 1.5) 📱 طريقة الجوال: حمّل الملفات الكاملة الآن وانقلها — تنصيب بلا إنترنت على الكمبيوتر

السكربت **يفحص أولاً** وجود ملفات التثبيت بجانبه ويستخدمها مباشرة **بدون أي إنترنت**.
حمّل هذه الملفات من متصفح جوالك (روابط مايكروسوفت الرسمية المباشرة — ملفات كاملة لا محمّلات):

| الملف | الرابط المباشر | الحجم |
|---|---|---|
| **SQL Server 2022 Express — الملف الكامل** ✅ | `https://download.microsoft.com/download/3/8/d/38de7036-2433-4207-8eae-06e247e17b25/SQLEXPR_x64_ENU.exe` | ~1.3 ج.ب |
| .NET 8 SDK — كامل | `https://aka.ms/dotnet/8.0/dotnet-sdk-win-x64.exe` | ~220 م.ب |
| **SSMS 20.2 — الملف الكامل ✅** (سمّه `SSMS-Setup-ENU.exe`) | `https://go.microsoft.com/fwlink/?linkid=2313753&clcid=0x409` | ~700 م.ب |
| بديل: SSMS 19.3 — آخر نسخة مؤكدة بملف واحد كامل، متوافقة تماماً مع SQL 2022 | `https://go.microsoft.com/fwlink/?linkid=2257624&clcid=0x409` | ~654 م.ب |
| Visual Studio 2022 — ⚠️ محمّل فقط (4 م.ب)؛ حزمه تُسحب على الكمبيوتر نفسه، وهو اختياري | `https://aka.ms/vs/17/release/vs_community.exe` | 4 م.ب + إنترنت لاحقاً |

> **سبب أن روابط SQL و SSMS التي حمّلتها كانت 4 ميجا**: مايكروسوفت صارت توزع في روابطها المختصرة (aka.ms)
> «محمّلات» صغيرة (SQL2022-SSEI-Expr.exe و vs_SSMS.exe) تكمل التنزيل على الكمبيوتر — وهذا لا ينفع مع إنترنت ضعيف.
> **الروابط في الجدول أعلاه كلها روابط رسمية مباشرة للملفات الكاملة** (موثقة في صفحة مايكروسوفت الرسمية
> Release history وفي ملخص downloadsqlserverexpress.com) وتُثبَّت بلا إنترنت:
> - SQL Server: الرابط الأول هو الملف الكامل الحقيقي SQLEXPR_x64_ENU.exe.
> - SSMS: **لا تستخدم** aka.ms/ssmsfullsetup للجوال — استخدم رابط SSMS 20.2 أو 19.3 من الجدول، وسمِّ الملف `SSMS-Setup-ENU.exe`.
> - للتحقق أو لغات أخرى: دخول مجاني إلى `my.visualstudio.com` ← Downloads ← SQL Server 2022 ← نسخة Express كاملة.

**طريقة الاستعمال بعد النقل:**
1. انقل الملفات من الجوال إلى الكمبيوتر (كابل USB أو Google Drive).
2. ضعها كما هي داخل مجلد **`Installer\OneClick`** بجانب `SETUP-FROM-ZERO.bat`:
   - `SQLEXPR_x64_ENU.exe` (أي اسم يبدأ بـ SQLEXPR وينتهي bـ .exe يُقبل)
   - `dotnet-sdk-8-win-x64.exe` · `SSMS-Setup-ENU.exe` · `vs_community.exe`
3. انقر `تنصيب_نظام_التصنيع.bat` — سترى رسالة «Offline ... found» لكل ملف موجود ويُثبَّت بلا إنترنت.

## 3) خطوات التنفيذ — نقرة واحدة

1. حمّل **`MfgSystem_1.50.50_FULL.zip`** من رابط التسليم.
2. استخرجه كاملاً إلى مجلد جديد: **`D:\MfgSystem`** (زر أيمن ← Extract All).
   ⚠️ مجلد جديد تماماً — لا فوق أي نسخة قديمة.
3. انقر مرتين على **`تنصيب_نظام_التصنيع.bat`** ← وافق على UAC بـ **Yes**.
4. راقب نقاط التفتيش:
   `[STEP 0]` صلاحية ← `[STEP 1]` إنترنت ← `[STEP 3]` ‏.NET ← `[STEP 4]` ‏SQL Server ←
   `[STEP 5]` ‏SSMS (اختياري) ← `[STEP 6]` ‏Visual Studio (الأطول) ← `[STEP 7]` بناء ← `[STEP 8]` تشغيل 🎉
5. النهاية: لافتة `ALL CHECKPOINTS PASSED - SYSTEM READY` و**نظام التصنيع** يفتح أمامك.

**فشل شيء؟** أصلح سبب سطر `[FAILED]` ثم **أعد نفس الملف** — المكتمل يُتخطى تلقائياً.

## 4) أول تشغيل

- تُنشأ قاعدة **`MfgSystemDB`** تلقائياً (جداول + بيانات أساسية + مستخدم admin) — بلا أي إعداد.
- الوضع الأول محلي (SQLite) ليعمل فوراً، وسيقترح النظام التحويل إلى SQL Express — اقبل.
- تغيير الاتصال يدوياً: **معلومات النظام ← تعديل الاتصال** — الخادم `.\SQLEXPRESS`، القاعدة `MfgSystemDB`، مصادقة Windows.
- كلمة سر SA الاحتياطية (لـ SSMS): `MfgSystem#2026Sa`

---

## 5) رؤية الشاشات وتعديلها — Visual Studio 2022

1. من `Installer\OneClick` انقر **`OPEN-VISUAL-STUDIO.bat`** (يفتح Visual Studio 2022 — البنفسجي الكبير، **ليس** VS Code).
2. كل الشاشات في `src\DatesErp.Desktop\Views\Screens\` — لكل شاشة ملفان:
   `.xaml` (التصميم — نقر مزدوج يفتح مصمماً مرئياً) و`.xaml.cs` (السلوك).
3. تجربة حية: **F5** (مع تصحيح) أو **Ctrl+F5** (عادي).

### ⚠️ قواعد الأمان عند التعديل اليدوي
- نسخة `.bak` قبل أي تعديل · تعديلات مظهر فقط ·
  **لا تغيّر أبداً** `x:Name` أو أسماء المعالجات مثل `Click="Save_Click"` ·
  التشغيل من المصدر يتصل بالقاعدة الحقيقية — استعرض بحذر.
