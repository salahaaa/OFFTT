# تحسينات مقترحة للنظام — 1.50.65 (أماكن أخرى غير الأصناف المساعدة)

**التاريخ:** 2026-09-14  
**الهدف:** اقتراح تحسينات عملية في أماكن أخرى بالنظام بعد إكمال نظام الأصناف المساعدة وربط كراتين العملاء

---

## 1. المخازن والاستلام (Receiving / Lots / Balances)

### 1.1 ربط الاستلام بالجودة الأولية
**المشكلة:** الاستلام يدخل مباشرة للمخزون الخام قبل فحص جودة أولي، قد يدخل خام غير مطابق.
**التحسين:** 
- إضافة حالة `QualityHold` للدفعة عند الاستلام — لا تُستخدم في الإنتاج إلا بعد فحص قبول أولي سريع (مظهر/رطوبة)
- شاشة `ReceivingView` تضيف زر "فحص أولي" يحول Lot إلى `Available` أو `Quarantine`
- تقرير: دفعات تحت الفحص الأولي > 24 ساعة (تنبيه)

### 1.2 تتبع تاريخ صلاحية الدفعات
**المشكلة:** لا يوجد حقل ExpiryDate للدفعة — التمور لها مدة صلاحية.
**التحسين:**
- إضافة `ExpiryDate` و `ProductionDate` في `Lot` + تنبيهات قبل 30 يوم من الانتهاء
- تقرير أرصدة يقترب انتهاؤها + منع استخدام دفعات منتهية في خطط جديدة (حارس في `PlanningService`)

### 1.3 جرد المخزون الفعلي
**المشكلة:** لا يوجد تسوية جرد دورية — الأرصدة قد تختلف عن الواقع.
**التحسين:**
- شاشة `StockTakeView` جديدة: اختيار مخزن → عد فعلي → مقارنة بالنظام → تسوية بفارق + سبب
- حركة `Adjustment` مع توثيق المستخدم والجهاز

---

## 2. الإنتاج (Planning / Orders / Execution)

### 2.1 لوحة طاقة الورديات الحية
**المشكلة:** الطاقة تُفحص عند الإنشاء فقط، لا توجد رؤية حية لتحميل اليوم.
**التحسين:**
- شاشة `ShiftLoadBoardView`: جدول يوم/وردية/خط → السعة / المستخدم / المتبقي / نسبة التحميل بألوان
- تحديث لحظي عند إصدار أمر جديد
- تنبيه عند تجاوز 90% تحميل

### 2.2 توزيع تلقائي ذكي للخطة
**المشكلة:** توزيع بنود الخطة على الورديات يدوي.
**التحسين:**
- زر "توزيع تلقائي" في `PlanningView`: يوزع البنود على الورديات حسب:
  - أولوية العميل `PriorityNo`
  - طاقة الصنف `ProductShiftCapacity`
  - تاريخ تسليم العميل (إن وجد)
  - متبقي الدفعة `Lot.InStockQtyKg`
- يحترم `RequiresTreatment` (لا يوزع قبل انتهاء المعالجة)

### 2.3 تتبع توقفات الإنتاج بتفصيل
**المشكلة:** التوقفات تُسجل إجمالي ساعات فقط، بلا تصنيف.
**التحسين:**
- إضافة `DowntimeCategory` (كهرباء/ميكانيكا/نقص خام/نقص كراتين/جودة/تنظيف) + `DurationMinutes` + `RootCause`
- تقرير Pareto للتوقفات + KPI: OEE (التوافر × الأداء × الجودة)

### 2.4 ربط استهلاك الماء/الكهرباء بالأمر
**المشكلة:** لا تتبع لتكلفة التشغيل.
**التحسين:**
- إضافة حقول `WaterUsedLiters` و `ElectricityKwh` في `ProductionExecution`
- تقرير تكلفة إنتاج لكل كرتون (خام + مساعد + طاقة)

## 3. الجودة (Quality)

### 3.1 فحص الجودة المرحلي
**المشكلة:** فحص نهائي فقط، لا يوجد فحص أثناء التشغيل.
**التحسين:**
- إضافة `CheckType`: `InProcess` (كل ساعة) + `Final`
- شاشة `InProcessQualityView`: فحص سريع (وزن كرتون/مظهر/ختم) مع إيقاف خط تلقائي إذا تجاوز الهالك 5%
- ربطه بصرف كراتين: إذا فحص مرفوض، لا يصرف كراتين إضافية حتى تصحيح

### 3.2 مواصفات جودة لكل عميل
**المشكلة:** نفس معايير الجودة لكل العملاء، لكن كل عميل له مواصفة (سكري فاخر/عادي).
**التحسين:**
- جدول `CustomerQualitySpec`: عميل + صنف + وزن كرتون مسموح ± + نسبة حشف مسموحة + نوع كرتون
- عند فحص جودة، يقارن بمواصفة العميل لا العامة
- تنبيه إذا وزن الكرتون خارج مواصفة العميل

### 3.3 تتبع أسباب الرفض
**المشكلة:** المرفوض يُسجل كجم فقط بلا سبب.
**التحسين:**
- إضافة `RejectionReason` (وزن زائد/ناقص/كرتون تالف/ختم/تلوث/حشرات) + صور (اختياري)
- تقرير: أكثر أسباب الرفض تكراراً لكل خط/وردية/صنف

## 4. التسليم والعملاء (Delivery / Availability)

### 4.1 حجز متاح العميل
**المشكلة:** `CustomerAvailabilityBoardView` عرض فقط، لا حجز.
**التحسين:**
- زر "حجز" يحجز كمية للعميل (Reservation) بمدة صلاحية (24 ساعة) — يمنع بيعها لعميل آخر
- انتهاء الحجز تلقائياً + تنبيه
- تقرير حجوزات منتهية لم تُسلم

### 4.2 تسليم جزئي مع تتبع
**المشكلة:** التسليم كامل أو لا شيء.
**التحسين:**
- دعم تسليم جزئي لنفس الحجز: 1000 كرتون من 3500 → يبقى 2500 محجوز
- تتبع شحنة: رقم سيارة + سائق + وقت خروج + تأكيد استلام العميل (توقيع/صورة)

### 4.3 تسعير حسب العميل والكمية
**المشكلة:** لا يوجد تسعير.
**التحسين:**
- جدول `CustomerPricing`: عميل + صنف + سعر كرتون + خصم كمية + عملة
- عند التسليم، يحسب إجمالي قيمة + فاتورة مبدئية
- تقرير مبيعات حسب عميل/صنف/فترة

## 5. الأصناف المساعدة الموسعة (Auxiliary Extended)

### 5.1 ملصقات وأكياس خاصة بالعميل (تعميم فكرة الكراتين)
**المشكلة:** ربطنا الكراتين فقط، لكن الملصقات والأكياس أيضاً لها ماركات.
**التحسين:**
- نفس شاشة `CustomerCartonMappingView` توسع لتشمل: ملصق/كيس/شريط لاصق
- حقل `AuxiliaryGroup` (كرتون/ملصق/كيس) للفلترة
- عند إنتاج للسلطان: يخصم كرتون السلطان + ملصق السلطان + كيس السلطان تلقائياً

### 5.2 تتبع استهلاك مساعد فعلي vs محتسب
**المشكلة:** نحسب محتسب فقط، لا نسجل فعلي مستهلك أثناء التشغيل.
**التحسين:**
- في `ProductionDeliveryView` إضافة حقول: كراتين مستهلكة فعلياً، ملصقات تالفة، أكياس تالفة
- تقرير انحراف: محتسب 3500 / فعلي 3520 (هالك 20 بسبب تلف) — يحسب تكلفة هالك مساعد

### 5.3 طلب شراء تلقائي للمساعد
**المشكلة:** لا تنبيه عند قرب نفاد كراتين.
**التحسين:**
- عند وصول رصيد WAUX لكرتون ما < ReorderLevel، ينشئ تنبيه في `MyTasksView` + تقرير طلب شراء
- ربطه بالموردين: كل كرتون له مورد افتراضي

## 6. التقارير والتحليلات

### 6.1 لوحة مؤشرات إنتاجية يومية
**المشكلة:** التقارير منفصلة، لا لوحة واحدة.
**التحسين:**
- Dashboard جديد: إنتاج اليوم (كرتون/كجم)، نسبة إنجاز الخطط، توقفات اليوم، جودة اليوم (مقبول/مرفوض)، تسليم اليوم، أرصدة WAUX حرجة
- تحديث كل 5 دقائق + تصدير PDF يومي تلقائي

### 6.2 تقرير تكلفة أمر الإنتاج
**المشكلة:** لا يوجد تكلفة فعلية للأمر.
**التحسين:**
- تقرير: أمر OP-001 3500 كرتون سكري 8كجم
  - خام: 3600 كجم × سعر
  - مساعد: كراتين السلطان 3500 × سعر، ملصقات 3500، أكياس...
  - تشغيل: ساعات × تكلفة ساعة
  - إجمالي تكلفة / تكلفة كرتون
  - مقارنة بمخطط

### 6.3 تقرير أداء العملاء
**المشكلة:** لا يوجد تقييم للعملاء.
**التحسين:**
- تقرير: كل عميل → إجمالي مستلم خام، منتج، مسلم، متبقي، نسبة هالك، متوسط تأخير تسليم، أكثر شكاوى جودة
- يساعد في تحديد أولوية العملاء

## 7. النظام والأمان

### 7.1 صلاحيات دقيقة على المخازن
**المشكلة:** صلاحية عامة على المخزون.
**التحسين:**
- صلاحية لكل مخزن: WRM/WFG/WAUX — مستخدم مخزن خام لا يرى تام
- صلاحية صرف مساعد حسب المجموعة: كراتين فقط / ملصقات فقط

### 7.2 تسجيل دخول ببصمة/QR
**المشكلة:** كلمة مرور فقط.
**التحسين:**
- دعم تسجيل دخول سريع عبر QR للعمال في خط الإنتاج (بدون كتابة)
- تسجيل وقت دخول/خروج الوردية تلقائياً

### 7.3 نسخ احتياطي تلقائي مجدول
**المشكلة:** نسخ يدوي.
**التحسين:**
- جدولة نسخ يومي تلقائي + رفع إلى مجلد شبكة + تنبيه عند فشل
- اختبار استعادة تلقائي أسبوعي (يتحقق من سلامة النسخة)

## 8. UX وتحسينات واجهة

### 8.1 بحث شامل سريع (Ctrl+K)
**التحسين:** نافذة بحث تبحث في كل المستندات: أمر/خطة/دفعة/عميل/صنف → فتح مباشر
- مثل Spotlight — يوفر وقت كبير

### 8.2 اختصارات لوحة مفاتيح
- `Ctrl+N` أمر جديد، `Ctrl+S` حفظ، `Ctrl+P` طباعة، `F5` تحديث، `F2` تعديل
- تلميحات تظهر عند الضغط على `?`

### 8.3 وضع ليلي / تكبير خط
- زر تكبير خط للعمال كبار السن
- وضع ليلي لوردية الليل

## 9. أولويات مقترحة (MoSCoW)

### Must (شهر 1):
1. لوحة طاقة الورديات الحية (2.1) — يمنع تجاوز الطاقة
2. ملصقات وأكياس خاصة بالعميل (5.1) — تعميم فكرة الكراتين
3. حجز متاح العميل (4.1) — يمنع بيع نفس الكمية مرتين
4. فحص جودة مرحلي (3.1) — يقلل هالك

### Should (شهر 2-3):
5. تتبع صلاحية الدفعات (1.2)
6. تقرير تكلفة أمر الإنتاج (6.2)
7. تتبع أسباب الرفض (3.3)
8. طلب شراء تلقائي مساعد (5.3)

### Could (شهر 4+):
9. OEE وتوقفات مفصلة (2.3)
10. تسعير وفواتير (4.3)
11. بحث شامل Ctrl+K (8.1)
12. نسخ احتياطي مجدول (7.3)
