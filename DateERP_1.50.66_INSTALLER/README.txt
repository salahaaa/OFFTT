DateERP 1.50.66 - ONE CLICK INSTALL
================================

تعليمات التثبيت للمستخدم النهائي:

1. فك الضغط عن الملف DateERP_1.50.66_ONE_CLICK_INSTALL.zip
   ستحصل على مجلد اسمه DateERP_1.50.66_INSTALLER

2. ادخل الى المجلد DateERP_1.50.66_INSTALLER

3. اضغط بزر الفأرة الأيمن على ملف INSTALL-1.50.66.bat

4. اختر "تشغيل كمسؤول" (Run as administrator)

5. انتظر حتى تظهر رسالة:
   تم تثبيت DateERP 1.50.66 بنجاح

6. سيظهر اختصار على سطح المكتب باسم DateERP 1.50.66
   اضغط عليه لتشغيل النظام.

7. او شغل النظام من:
   D:\DateERP_1.50.66\RUN.bat
   او
   C:\DateERP_1.50.66\RUN.bat

ملاحظات مهمة:
- التثبيت لا يحذف قاعدة البيانات الموجودة ولا يحذف بياناتك.
- اذا كانت قاعدة البيانات غير موجودة، سيقوم النظام بإنشائها تلقائيا عند اول تشغيل.
- النسخة الجديدة مستقلة تماما في مجلد D:\DateERP_1.50.66 او C:\DateERP_1.50.66
- لا تستخدم ملفات من نسخ قديمة مثل D:\DateERP_Publish او C:\DateERP
- اذا واجهت مشكلة، ارسل ملف install_1.50.66.log الموجود بجانب برنامج التثبيت.

للتحقق قبل التثبيت (اختياري):
- شغل VERIFY-INSTALLER.bat
- يجب ان تظهر رسالة INSTALLER PACKAGE READY

DateERP 1.50.66 - User Guide (English)

1. Extract DateERP_1.50.66_ONE_CLICK_INSTALL.zip
2. Open folder DateERP_1.50.66_INSTALLER
3. Right-click INSTALL-1.50.66.bat -> Run as administrator
4. Wait until you see: DateERP 1.50.66 installed successfully
5. Use desktop shortcut DateERP 1.50.66 to run the system.

The installer does NOT delete your existing database.
If database does not exist, it will be created automatically on first run.
