# دليل تركيب وتشغيل MfgSystem 1.50.72

## التثبيت المكتبي المحلي — المسار الافتراضي

1. استخرج ZIP الفرع الحالي إلى مجلد جديد، مثل `D:\MfgSystem_1.50.72`. لا تضع الملفات فوق نسخة DateERP قديمة.
2. شغّل `INSTALL-AND-RUN.bat` من جذر المصدر بصفة مسؤول.
3. يتأكد المثبّت من .NET 8 SDK، يستعيد حزم NuGet، ثم ينشر نسخة win-x64 ذاتية التشغيل في `Application_1.50.72` وينشئ اختصاراً.
4. شغّل `MfgSystem.exe` أو اختصار سطح المكتب. عند أول تشغيل دون إعداد MfgSystem سابق، ينشأ ملف `%LocalAppData%\MfgSystem\mfgsystem_local.db` وتُهيأ الجداول والبيانات الأساسية تلقائياً.
5. بيانات الدخول الأولية: المستخدم `admin` وكلمة المرور `Admin@123`؛ يفرض النظام تغييرها عند أول دخول. لا تتركها للاستخدام الإنتاجي.

يحتاج استرجاع الحزم إلى الإنترنت أو إلى مخزن NuGet محلي كامل. عند التحضير من جهاز آخر يمكن تنزيل مثبت SDK الرسمي x64 من [رابط .NET 8](https://aka.ms/dotnet/8.0/dotnet-sdk-win-x64.exe)، ثم وضعه بجوار BAT باسم `dotnet-sdk-8-win-x64.exe`. هذا لا يوفر حزم NuGet غير الموجودة محلياً. المثبّت لا يثبت Visual Studio أو SQL Server أو SSMS.

## استقلال البيانات

- إعداد MfgSystem والسجلات والثيمات والمسودات تحت `%LocalAppData%\MfgSystem`؛ النسخ قبل ترحيل SQL تحت `Documents\MfgSystem\Backups`.
- شاشة النسخ والاستعادة مخصصة لـ SQL Server فقط؛ SQLite المحلية لا تدعمها هذه الشاشة.
- لا يستورد النظام إعدادات أو قواعد `DateERP` السابقة ولا يحذفها أو يستبدلها.
- إذا وجد إعداد سابق لهوية MfgSystem نفسها، يحافظ عليه المثبّت؛ لا يمسح قاعدة أو ملف مستخدم لإجبار التهيئة من جديد.
- مخرجات النشر في مجلد مستقل `Application_1.50.72`، والبيانات ليست داخل مجلد ملفات البرنامج.

## استخدام SQL Server مركزي (اختياري)

التثبيت الافتراضي SQLite أحادي الجهاز. للاستخدام متعدد الأجهزة، جهّز SQL Server وقاعدة مستقلة `MfgSystemDB` يدوياً، ثم استخدم شاشة إعداد الاتصال في التطبيق. يمكن مراجعة `Installer/server/إعداد_قاعدة_البيانات.sql` لإعداد قاعدة جديدة؛ يتوقف السكربت دون تغيير عند وجود `MfgSystemDB` مسبقاً. يجب فحص صلاحيات الخادم وسياسة النسخ قبل التنفيذ. قاعدة `DateFactory` ليست قاعدة هذا الإصدار.

ملف `Installer/server/إعداد_النسخ_الاحتياطي.sql` اختياري ويتطلب SQL Server Agent؛ إصدار Express لا يوفّر SQL Server Agent. التثبيت بنقرة واحدة لا يشغل أي ملف SQL.

## التحديث

لا تستخدم `UPDATE-AND-RUN.bat` على مجلد تثبيت DateERP سابق. في هذا المشروع، احتفظ بنسخة مستقلة لكل مصدر/إصدار واتبع مسار التحديث المخصص فقط بعد أخذ نسخة احتياطية واختبارها. المثبّت الأولي الحالي لا ينقل بيانات MfgSystem قديمة ولا يغيّر ملف إعداد موجوداً.

## حدود الاختبار

ملفات CMD/BAT وPowerShell وWPF لم تُشغّل على Windows في بيئة إعداد هذا الدليل؛ كما لم يُنفّذ بناء .NET هنا. يجب إجراء اختبار قبول على Windows (تثبيت نظيف، أول تشغيل، إعادة تشغيل، واختبار النسخ الاحتياطي) قبل الاستخدام الإنتاجي.
