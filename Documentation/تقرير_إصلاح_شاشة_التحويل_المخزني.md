## 2. النماذج الفعلية التي اعتُمد عليها (موجودة مسبقاً)

- `StockBalance` (المخزن + صنف/مادة + دفعة + عميل + عبوة → QtyKg/PackageCount) — الرصيد الجاري.
- `InventoryTransaction` (حركة مرتبطة دائماً بمستند: `ReferenceDocType` + `ReferenceDocNumber`).
- `ServiceBase.PostStockMovement(...)` — الدالة الموحدة التي تستخدمها كل الخدمات: تحدّث الرصيد، تمنع السالب، تمنع تكرار نفس الحركة لنفس المستند، تمنع خلط العملاء، وتُنشئ الحركة برقم `TXN`.
- `ServiceBase.RunOp/RunInTransaction` — معاملة ذرية + ترجمة أخطاء الأعمال إلى `OpResult`.
- `MovementType.Transfer` كان معرّفاً في التعداد لكن غير مستخدم؛ أُبقي عليه، والتحويل يُقيَّد كما تفعل المعالجة (`TreatmentStart`): **صادر من المصدر + وارد للمستلم** حتى تبقى تقارير الوارد/الصادر لكل مخزن صحيحة.
- `SchemaMigrator` — ينشئ الجداول والأعمدة المفقودة تلقائياً عند الإقلاع بلا حذف بيانات ⇒ لا حاجة لترحيل يدوي.

## 4. سلوك الخدمة `WarehouseTransferService` (مورد الصلاحيات: `inventory`)

| العملية | الصلاحية | السلوك |
|---|---|---|
| `GetStockByWarehouse` | View | أرصدة `StockBalances` غير الصفرية لمخزن محدد بأسماء الصنف/المادة/الدفعة/العميل/العبوة. |
| `SaveTransfer` | Create | تحقق: مخزنان مختلفان فعّالان، بند واحد على الأقل، كمية > 0، عبوات ≥ 0، **لا تكرار لنفس مفتاح الرصيد**، **كل بند ≤ المتاح في المصدر** لنفس الدفعة/العميل/العبوة. يحفظ مسودة برقم `WHT` — **لا أثر على المخزون**. |
| `UpdateTransfer` | Edit | تعديل مسودة بنفس رقمها (بدل حذف+إنشاء). مرفوض للمعتمد/الملغي. |
| `ApproveTransfer` | Approve | في معاملة واحدة: لكل بند `PostStockMovement(المصدر, Outbound)` ثم `PostStockMovement(المستلم, Inbound)` بالمرجع `(WarehouseTransfer, رقم السند)` وبنفس الدفعة/العميل/العبوة. أي فشل (رصيد غير كافٍ، تكرار) ⇒ تراجع كامل، لا رصيد غير متطابق. حماية مزدوجة ضد التكرار: حالة السند + وجود حركات بنفس المرجع + فحص التكرار داخل `PostStockMovement`. |
| `CancelTransfer` | Cancel | مسودة ⇒ ملغية بلا أثر. معتمد ⇒ عكس الحركتين بالمرجع `رقم السند#REV` (سحب من المستلم — يفشل إن صُرفت الكمية هناك — ثم إعادة للمصدر) ثم الحالة «ملغي» مع السبب. |
| `DeleteDraft` | Delete | حذف مسودة فقط؛ المعتمد لا يُحذف. |

المتبقي/المتاح يُقرأ دائماً من `StockBalances` (نتيجة الحركات) لا من قيمة مخزنة في السند.

## 5. الشاشة

- شريط العمليات الكامل: جديد / حفظ المسودة / بحث (نافذة البحث الموحدة برقم/مخزن/حالة) / تراجع / اعتماد وتنفيذ / إلغاء (عكس) / حذف المسودة / طباعة / Excel / تنقل أول-سابق-تالي-أخير / القائمة / تحديث / خروج — كل زر موصول بعملية فعلية ورسالة.
- اختيار الصنف **من رصيد المخزن المصدر فقط** (نقر مزدوج على سطر الرصيد، زر «إضافة من الرصيد»، «تحويل كامل الرصيد»، أو زر الصنف في البند الذي يفتح نافذة بحث في أرصدة المصدر). لا يمكن إدخال صنف بلا رصيد.
- منع التكرار (نفس الصنف/الدفعة/العميل/العبوة) ومنع تجاوز المتاح في الواجهة، والخدمة تعيد التحقق إلزامياً.
- تغيير المخزن المصدر على مسودة قيد الإدخال يفرّغ البنود (لأنها تخص رصيد مخزن آخر).
- بعد الاعتماد: رسالة تتضمن **رصيد المصدر قبل/بعد**، ويُعاد تحميل الأرصدة والسند مقفلاً.
- قفل كامل للرأس والبنود عند الاعتماد/الإلغاء؛ تمكين/تعطيل الأزرار حسب الحالة.
- لا بيانات تجريبية ولا مخزن ثابت: المخازن من الجدول، والاختيار الافتراضي مجرد اقتراح.
