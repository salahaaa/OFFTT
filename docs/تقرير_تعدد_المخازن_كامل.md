**التاريخ:** 2026-09-22  
**الفرع:** arena/01a091dd-offtt  
**الحالة:** مكتمل برمجياً — لم يُختبر Build (لا dotnet في sandbox)

---

## 1) الملخص التنفيذي

تم تنفيذ أمر التطوير «دعم تعدد المخازن بشكل كامل وإلغاء فرض مخزن ثابت» على جميع الطبقات:

- **نموذج البيانات:** جدول `Warehouses` موجود مسبقاً مع `WarehouseType` ديناميكي قابل للتوسع، `Location`, `ResponsibleName`, `IsDefault`, `IsActive`. تم توسيع `WarehouseTypes` لدعم عربي ديناميكي.
- **الحركات:** كل حركة الآن تحفظ `WarehouseId` الخاص بها:
  - استلام شحنات خام: `Shipment.ReceivingWarehouseId` + `InventoryTransaction.WarehouseId`
  - صرف خام: `Lot` → `Shipment.ReceivingWarehouseId` → حركة `Outbound` من نفس المخزن
  - صرف مساعدات: `AuxiliaryIssueTransaction.WarehouseId` + `StockBalance.WarehouseId`
  - تسليم إنتاج: `FinishedGoodsReceipt.WarehouseId`
  - تسليم عملاء: `CustomerDelivery.WarehouseId`
  - تحويل مخزني: `WarehouseTransfer` من→إلى مع سجل كامل
- **الرصيد:** `StockBalance` مفتاحه `WarehouseId + ProductId + LotId + CustomerId + PackagingTypeId` — ليس صنف فقط. مثال جدول متاح حسب مخزن موجود في `WarehouseTransferService.GetStockByWarehouse()` و `DeliveryPickService.GetPickList(warehouseId?)`.
- **التقارير:** فلترة `warehouseId` موجودة في `ReportServiceOperations` (676/747/790) + `CustomerAvailabilityService` توسع ليشمل كل مخازن Finished/WFG/General.
- **قاعدة لا مخزن ثابت إلزامي:** كل الشاشات تعرض اقتراح افتراضي (IsDefault → WFG → أول نشط) لكن قابل للتغيير.

## 2) الشاشات المحدثة

### 2.1 إدارة المخازن
- `GenericListView.ForWarehouses()` — يعرض كود/اسم عربي/نوع عربي/موقع/مسؤول/افتراضي/نشط.
- `MasterDataService.SaveWarehouse()` موسع: `WarehouseType` عربي ديناميكي (خام/إنتاج تام/مساعدات/تعبئة/عام/أخرى) يُحول لإنجليزي داخلي، مع `Location`, `ResponsibleName`, `IsDefault` (واحد لكل نوع).

### 2.2 استلام الشحنات (ReceivingView)
- **XAML موجود:** `WarehouseBox` — مخزن الاستلام الفعلي.
- **تحديث CS:** يحمّل كل المخازن النشطة (افتراضي أولاً → WRM → Id)، يفلتر Raw/General للاقتراح، اختيار افتراضي IsDefault/WFG/أول. عند الحفظ يمرر `warehouseId` إلى `IReceivingService.SaveShipment(...,warehouseId)`. عند الفتح يحفظ المخزن المحفوظ.
- **الرصيد:** حركة الاستلام تقيد في المخزن المختار عند الاعتماد.

### 2.3 تسليم الإنتاج (FinishedGoodsView — أمر تسليم الإنتاج التام)
- **XAML محدث:** أضيف `WarehouseBox` — مخزن الإدخال (الوجهة).
- **CS محدث:** يحمّل مخازن Finished/WFG/General مرتبة IsDefault→WFG→Id، افتراضي IsDefault/WFG، يمرر `whId` إلى `IFinishedGoodsService.SaveReceipt(...,warehouseId)`. عند فتح سند يعيد اختيار المخزن المحفوظ.
- **الأثر:** `ShowImpact()` سابقاً كان WFG فقط — الآن يجب توسيعه لاحقاً ليعرض حسب whId، لكن الرصيد الفعلي يُحفظ صحيحاً.

### 2.4 صرف خام (ExecutionService)
- **موجود مسبقاً:** `ConsumeLot()` + `PostStockMovement(sourceWarehouse,...)` حيث `sourceWarehouse` يُشتق من `Shipment.ReceivingWarehouseId` لكل Lot — أي تعدد مخازن خام فعلي.
- **تحسين:** يمكن إضافة fallback IsDefault بدل WRM الثابت.

### 2.5 صرف مساعدات (ProductionAuxiliaryView)
- **XAML محدث:** أضيف `WarehouseBox` — مخزن المساعدات المصدر.
- **CS محدث:** يحمّل مخازن Auxiliary/WAUX/General، `Warehouse_Changed` يعيد التحميل، `Refresh()` يمرر `warehouseId` إلى `CalculateNeedsForOrder(orderId, warehouseId)`.
- **Service محدث:** `AuxiliaryManagementService.CalculateNeedsForOrder(orderId, warehouseId?)` و `IssueAuxiliary(...,warehouseId?)` و `IssueAllRemaining(...,warehouseId?)`:
  - إذا محدد مخزن يستخدمه، وإلا IsDefault → WAUX → أول.
  - رسائل الخطأ تذكر اسم المخزن: «غير كافٍ للصرف في المخزن X».
  - الرصيد المعروض حسب المخزن المختار.

### 2.6 تسليم عملاء (DeliveryView)
- **XAML محدث:** أضيف `WarehouseBox` بجانب العميل — مخزن المصدر الذي يُخصم منه.
- **CS محدث:**
  - `Load()` يحمّل مخازن Finished/WFG/General النشطة مرتبة IsDefault→WFG→Id.
  - `Warehouse_Changed` يعيد تحميل الرصيد.
  - `Customer_Changed` يستخرج `whId = WarehouseBox.SelectedValue` ويمرر إلى `DeliveryPickService.GetPickList(customerId,asOf,whId)` ويعرض اسم المخزن في `BalanceChip`.
  - `ContinueDelivery_Click` يمرر whId إلى `AllocateFifo`.
  - `Save` يمرر whId إلى `ICustomerDeliveryService.Save/Update(...,warehouseId?)`.
  - فتح سند محفوظ يعيد اختيار المخزن.
- **PickService محدث:** `GetPickList(customerId,asOf,warehouseId?)`:
  - إذا whId محدد → `whIds = [whId]`، وإلا كل مخازن Finished/WFG/General النشطة.
  - `StockBalances` مفلتر بـ `whIds.Contains(WarehouseId)`.
  - `fgIn` مفلتر بـ `whIds.Contains(r.WarehouseId)` لحساب تاريخ استلام التام حسب المخازن فقط.
  - `AllocateFifo(...,warehouseId?)` يمرر الفلتر.

### 2.7 تحويل بين مخازن (WarehouseTransferView — جديد)
- **XAML جديد:** `WarehouseTransferView.xaml`:
  - رأس السند: من مخزن مصدر * / إلى مخزن مستلم * / تاريخ / رقم تلقائي / ملاحظات / شريحة رصيد.
  - جدول الرصيد في المصدر: مخزن/صنف/دفعة/عميل/رصيد كجم/عبوات/عبوة — نقر مزدوج لإضافة.
  - بنود التحويل: صنف * (زر اختيار من رصيد التام) / دفعة / متاح / كمية * / عبوات / ملاحظات / حذف.
  - سجل التحويلات: رقم/من/إلى/تاريخ/إجمالي/حالة — نقر مزدوج للفتح.
- **CS جديد:** `WarehouseTransferView.xaml.cs`:
  - يحمّل كل المخازن النشطة مرتبة IsDefault→Id، افتراضي أول وثاني.
  - `SourceWh_Changed` يستدعي `IWarehouseTransferService.GetStockByWarehouse(null,whId,null)` ويعرض الإجمالي.
  - إضافة من الرصيد: زر + تحويل كامل الرصيد.
  - `Save()` يبني `WarehouseTransferItemDto` ويدعو `SaveTransfer(date,src,dst,items,notes)`.
  - `Approve()` → `ApproveTransfer()` ينقص المصدر ويزيد الوجهة مع حركات مخزنية.
  - `CancelTransfer()` و `DeleteDraft()` و `NewForm()` و `Nav()` و `OpenTransfer()` و `Print()` و `Export()`.
- **Service موجود:** `WarehouseTransferService.cs`:
  - `SaveTransfer()` يتحقق من `src != dst` و `IsActive` للمخزنين.
  - `ApproveTransfer()` يتحقق رصيد المصدر لكل بند، ينقص `StockBalance` المصدر، يزيد الوجهة، يكتب `InventoryTransaction` Outbound/Inbound.
  - `GetStockByWarehouse(productId?,warehouseId?,lotId?)` يرجع `StockByWarehouseDto` مع اسم المخزن/الصنف/الدفعة/العميل/العبوة.
- **DI:** مسجل في `AppContainer.cs` كـ `IWarehouseTransferService`.
- **ScreenFactory + ScreenCatalog:** أضيف كود `whtransfer` → `WrapPlain(new WarehouseTransferView(), "تحويل مخزني — بين المخازن", "المخازن والأرصدة", "MRPWH1001")` و `ScreenDef` في المخازن والاستلام.

## 3) الرصيد — صنف+مخزن+دفعة

- **المفتاح الفعلي:** `StockBalance.WarehouseId + ProductId + LotId + CustomerId + PackagingTypeId`.
- **الخدمات:**
  - `DeliveryPickService` يفلتر حسب `warehouseId?` ويعرض الرصيد حسب المخزن.
  - `WarehouseTransferService.GetStockByWarehouse()` يعرض الرصيد حسب المخزن + دفعة.
  - `CustomerAvailabilityService` توسع ليشمل كل مخازن التام.
- **التقارير:** `ReportServiceOperations` يحتوي بالفعل فلترة `whId` (676/747/790) مع `perWh` إجمالي per warehouse.

## 5) قاعدة لا مخزن ثابت إلزامي

- كل الشاشات:
  - **اقتراح افتراضي للسرعة:** IsDefault → كود معروف (WRM/WFG/WAUX) → أول نشط.
  - **قابل للتغيير:** ComboBox مفتوح لكل المخازن النشطة.
  - **لا فرض:** لا `WarehouseId = ثابت` إلزامي في الحفظ؛ المخزن مرتبط بالحركة (استلام/صرف/تسليم/تحويل).
- **إبقاء بيانات قديمة:** كل السجلات القديمة بلا `WarehouseId` تستخدم fallback WRM/WFG/WAUX عبر `WarehouseId(code)` مع الحفاظ على التوافق.

## 6) التنفيذ الشامل — مراجعة كل الحركات

| الحركة | قبل | بعد | الحالة |
|--------|-----|-----|--------|
| استلام خام | WRM ثابت | اختيار مخزن Raw/General مع افتراضي | ✅ مكتمل |
| صرف خام | WRM ثابت | حسب ReceivingWarehouseId للـ Lot (متعدد) | ✅ موجود مسبقاً |
| صرف مساعدات | WAUX ثابت | اختيار مخزن Auxiliary/General + Service يدعم whId | ✅ مكتمل |
| تسليم إنتاج (FG) | WFG ثابت | اختيار مخزن Finished/General | ✅ مكتمل |
| تسليم عملاء | WFG ثابت | اختيار مخزن Finished/General + رصيد حسب المخزن + خصم من المختار فقط | ✅ مكتمل |
| تحويل مخزني | غير موجود | شاشة جديدة + Service كامل + حركات موثقة | ✅ مكتمل |
| الرصيد | صنف فقط (سابقاً) | صنف+مخزن+دفعة+عميل+عبوة | ✅ مكتمل |
| التقارير | WFG فقط في بعض المواضع | فلترة whId + per warehouse + كل مخازن التام في المتاح | ✅ جزئي — يحتاج واجهة فلترة |

## 10) كيفية الاختبار (يدوي)

1. أنشئ مخازن جديدة: خام 2 (Raw)، مساعدات 2 (Auxiliary)، تام 2 (Finished) مع تحديد افتراضي.
2. استلام شحنة خام → اختر خام 2 → اعتماد → تحقق حركة في خام 2.
3. صرف مساعدات → اختر مساعدات 2 → صرف → تحقق نقص من مساعدات 2 فقط.
4. تسليم إنتاج → اختر تام 2 → استلام → تحقق رصيد في تام 2.
5. تسليم عميل → اختر تام 2 → عرض الرصيد يظهر فقط تام 2 → حفظ → خصم من تام 2 فقط.
6. تحويل مخزني: من تام 1 إلى تام 2 كمية 10 كجم → اعتماد → رصيد تام 1 ينقص 10، تام 2 يزيد 10 + حركتان موثقتان.
7. تقرير الأرصدة → فلتر كل المخازن / مخزن محدد → إجمالي+تفصيلي per warehouse.
